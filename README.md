# Taskwipe

Show a web task once in your own Chrome tab, or hand it a prompt and a file. Taskwipe compiles a skill, remembers the personal bits and the way you write, and can do it again on a different page.

The rebuild spec is [docs/HOW_IT_WAS_BUILT.md](docs/HOW_IT_WAS_BUILT.md). Follow that file, not this one.

Two in-depth local demos (apply with a CV, then parcel + caption) are in [docs/DEMOS.md](docs/DEMOS.md). The hub is `http://127.0.0.1:8001/demo/` once the API is running.
